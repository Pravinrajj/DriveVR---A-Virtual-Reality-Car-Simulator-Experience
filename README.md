# 🚗 DriveVR — A Virtual Reality Car Simulator Experience

DriveVR is an immersive Virtual Reality (VR) project that simulates driving a car using **hand-tracking gestures instead of a physical steering wheel or controller**. The goal is to bring realistic, intuitive, and accessible driving mechanics into VR by enabling **gesture-based control**.

---

## 🎯 Project Overview

Traditional VR driving simulations rely on handheld controllers or external steering peripherals.  
DriveVR eliminates this dependency by integrating **real-time hand tracking**, allowing users to:

- Steer using hand movements
- Accelerate and brake using gestures
- Interact with the environment without physical input devices

The project demonstrates a future where VR driving becomes more natural, immersive, and controller-free.
